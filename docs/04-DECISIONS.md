Every rule in `AGENTS.md` traces back to an entry here. To change a rule, add a new ADR that supersedes the old one, never edit history silently.

Status: **Accepted** = user decided. **Accepted (proposed)** = Claude proposed an industry default on 2026-10-08, the user can veto it. **Open** = waiting for the user.
