6. `newId()` is written by hand (no dependency), following RFC 9562 UUID v7:
   - 48-bit Unix ms timestamp
   - version `7`
   - a 12-bit `rand_a` used as a **monotonic counter** inside the same millisecond (RFC 9562 §6.2 method 1), seeded randomly each new millisecond
   - variant `10`
   - 62 random bits from `globalThis.crypto.getRandomValues`
   - If the counter overflows within one ms, the generator moves on to the next ms value. If the clock goes backwards, it keeps the last timestamp.
   - Why: pure and isomorphic (browser + Node ≥ 20), and IDs created in sequence always sort ascending, which the ordering test needs.
7. ID types are branded strings: `type Id<EntityName extends string> = string & { readonly __brand: EntityName }`. 0.1 declares only the Phase 1 entities: `UserId`, `OrganizationId`, `LocationId`, `MemberId`, `RoleId`, `InvitationId`. Later cards add their own types (add-only).
8. All packages are ESM (`"type": "module"`), TypeScript `module`/`moduleResolution` `NodeNext`, `strict: true`, built with `tsc` to `dist/`, exported through an `exports` map. Turbo runs `build`, `typecheck` and `test` with `dependsOn: ["^build"]`.
9. Vitest is added in 0.1 because `ids` must ship tests. Card 0.2 adds the rest of the tooling (ESLint, Prettier, husky, CI). No ESLint config is created here; the old `.eslintrc.json` is removed.
10. `@banijjik/contracts` gets only `defineEnum()` (the `05` constant pattern as one tested helper), so the package has real code and later cards stop repeating the `Object.fromEntries` cast. No enums are added in 0.1.
11. `@banijjik/validation` gets only `uuidV7Schema` (Zod 4), built on `isUuidV7` from `@banijjik/ids`.
12. `@banijjik/config` holds `tsconfig.base.json` (shared strict options) and `tsconfig.library.json` (for packages). The root `tsconfig.base.json` is removed.
13. `package-lock.json` is deleted and regenerated by `npm install`.

## Interfaces & types
```ts
// @banijjik/ids
export type Id<EntityName extends string> = string & { readonly __brand: EntityName };
export type UserId = Id<"User">;
export type OrganizationId = Id<"Organization">;
export type LocationId = Id<"Location">;
export type MemberId = Id<"Member">;
export type RoleId = Id<"Role">;
export type InvitationId = Id<"Invitation">;

/** Creates a new lowercase UUID v7. The only ID generator in the codebase (ADR-036). */
export function newId<IdType extends Id<string> = Id<string>>(): IdType;

export const UUID_V7_PATTERN: RegExp; // /^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/
/** True when the value is a lowercase canonical UUID v7 string. */
export function isUuidV7(value: unknown): value is string;

/** Narrows a validated string to a branded ID. Throws InvalidIdError when it is not a UUID v7. */
export function asId<IdType extends Id<string>>(value: string): IdType;
export class InvalidIdError extends Error {} // message: "ids.invalid_uuid_v7" (an i18n-style key, no user text)

// @banijjik/contracts
/** Builds the `05` constant pattern: { A: "A", B: "B" } from a readonly tuple. */
export function defineEnum<const Values extends readonly string[]>(
  values: Values,
): { readonly [Key in Values[number]]: Key };

// @banijjik/validation
/** Zod schema for any domain ID (UUID v7, lowercase). */
export const uuidV7Schema: z.ZodType<string>;
```
- `newId` keeps its monotonic state (last ms, counter) in module scope. That state is private; no other export reads it.
- No `any`. The `as` casts in `newId`/`asId` carry a one-line comment saying why they are safe (`05`).
- Each function ≤ 40 lines; byte/hex helpers are private functions in the same file with full-word names (`writeTimestamp`, `bytesToHex`).

## Tests (must exist and pass)
`packages/ids`:
- [ ] `newId` returns a string matching `UUID_V7_PATTERN` (1 000 samples)
- [ ] the version nibble is `7` and the variant bits are `10`
- [ ] the embedded timestamp equals `Date.now()` at creation (± 1 ms)
- [ ] 10 000 IDs generated in a loop are strictly ascending as strings (same-millisecond ordering)
- [ ] 10 000 IDs are unique
- [ ] when the clock goes backwards (mocked `Date.now`), the next ID still sorts after the previous one
- [ ] `isUuidV7` rejects a v4 UUID, an uppercase v7, a missing hyphen, a non-string and an empty string
- [ ] `asId` returns the same string for a valid v7 and throws `InvalidIdError` for an invalid one

`packages/contracts`:
- [ ] `defineEnum(["A", "B"])` returns `{ A: "A", B: "B" }` and the result is frozen

`packages/validation`:
- [ ] `uuidV7Schema` accepts a `newId()` value and rejects a v4 UUID with a Zod error
