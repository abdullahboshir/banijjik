## Decisions
1. **Two branches, in this order.**
   - (a) `archive/v0` is created from `main` and receives **one** commit with the legacy uncommitted changes, so nothing of v0 is lost.
   - (b) `s/0.1-skeleton` is created from `main` (not from the archive) and does all removals and the new skeleton.
   - The implementer does **not** merge into `main` and does **not** push. The owner reviews and merges. Pushing `archive/v0` is the owner's choice.
2. **Local secrets are moved, not deleted.** Before removing `apps/`, move every `.env*` file under `apps/`, `packages/` and `libs/` to `../banijjik-local-backup/` (a sibling folder **outside** the repo, keeping relative paths). Tell the owner in the handoff. These secrets are compromised (P1) and must be rotated anyway.
3. **`apps/api` and `infra/` are NOT created in this card.** The roadmap text listed them, but AGENTS.md forbids empty or placeholder packages and folders. `infra/` (docker-compose) arrives in 0.3; `apps/api` arrives in 0.4 with real kernel code. Update roadmap card 0.1 text to match (see Files).
4. **ESM everywhere.** Root and packages use `"type": "module"`. TypeScript `module`/`moduleResolution` = `NodeNext`. Packages compile with `tsc` to `dist/` (JS + `.d.ts` + source maps). Each package's `exports` points to `dist`. Turborepo builds dependencies first (`dependsOn: ["^build"]`).
5. **Versions.**
   - Node engines `>=22.12`. Local is 24, also fine.
   - `packageManager: "npm@11.9.0"`.
   - Dependencies: install the **latest stable** `typescript`, `turbo`, `vitest`, `zod` (major 4) and `uuid` (a major that exports `v7`) at implementation time, with caret ranges.
   - Record the exact installed versions in the handoff.
   - If the latest TypeScript is a new major (6+) and something in this plan fails because of it, stop and ask. Do not downgrade silently.
6. **Vitest is added now** (root dev dependency), because `ids`, `contracts` and `validation` ship with tests. ESLint, Prettier, husky, commitlint and CI are card 0.2. Do not add them here.
7. **`@banijjik/ids` uses the `uuid` package's `v7`** (well-tested, isomorphic, works in browser and Node). It is the only place in the repo that generates IDs (ADR-036). Lowercase canonical output is enforced.
8. **Branded ID types** for every ID named in `09 §1.1` (+ D3/D4 additions) are declared now, so later cards import them instead of inventing their own.
9. **`@banijjik/contracts` starts with only what is already decided and needed by 0.2–0.4:**
   - a `defineEnum` helper that implements the contracts pattern of `05` once
   - `ERROR_CODE` (+ HTTP status map) from `14 §3`
   - `OFFERING_KIND` from `09`
   - Money types (`Money`, `CurrencyCode` = `BDT` only for now) **as types only**. Money arithmetic/allocation is card 0.4.
10. **`@banijjik/validation` starts with shared primitives only:** `uuidV7Schema`, `idSchema<TBrand>()`, `moneySchema`, `paginationQuerySchema` (page ≥ 1, 1 ≤ limit ≤ 100, default 20, `includeTotal` boolean). Entity schemas come with their cards.
11. **`.gitignore`** gains `coverage` and `*.tsbuildinfo` stays. No other change.

// define-enum.ts: the 05 contracts pattern, written once
export function defineEnum<const TValues extends readonly [string, ...string[]]>(
  values: TValues,
): { readonly values: TValues; readonly is: (value: unknown) => value is TValues[number] }
  & { readonly [K in TValues[number]]: K };
export type EnumValue<TEnum extends { values: readonly string[] }> = TEnum["values"][number];

// errors/error-code.ts
export const ERROR_CODE = defineEnum([
  "VALIDATION_ERROR", "UNAUTHENTICATED", "FORBIDDEN", "MODULE_DISABLED", "ORG_READ_ONLY",
  "ORG_SUSPENDED", "LOCATION_FORBIDDEN", "APPROVAL_REQUIRED", "NOT_FOUND", "CONFLICT",
  "INVALID_TRANSITION", "DUPLICATE", "INSUFFICIENT_STOCK", "SLOT_UNAVAILABLE", "CAPACITY_FULL",
  "IDEMPOTENCY_MISMATCH", "LIMIT_REACHED", "BUSINESS_RULE", "RATE_LIMITED", "INTERNAL",
] as const);
export type ErrorCode = EnumValue<typeof ERROR_CODE>;
export const ERROR_HTTP_STATUS: Readonly<Record<ErrorCode, number>>; // values exactly per 14 §3

// catalog/offering-kind.ts

## Tests (must exist and pass)
- [ ] `ids`: `newId()` matches the v7 regex and is lowercase
- [ ] `ids`: 10,000 calls produce 10,000 unique values
- [ ] `ids`: IDs created one after another sort ascending as strings (time order)
- [ ] `ids`: `isUuidV7` rejects a v4 UUID, an uppercase v7, an empty string and a non-UUID
- [ ] `ids`: `toId` returns the same string for a valid v7 and throws `InvalidIdError` (with `value`) for invalid input
- [ ] `contracts`: `defineEnum` exposes `values` in order, an object whose keys equal their values, and `is()` narrowing (true for members, false for others/non-strings)
- [ ] `contracts`: `ERROR_HTTP_STATUS` has an entry for every `ERROR_CODE` value, and the numbers equal `14 §3` (table-driven test)
- [ ] `validation`: `uuidV7Schema`/`idSchema` accept v7 and reject v4/uppercase/garbage
- [ ] `validation`: `moneySchema` rejects non-integers, unsafe integers and unknown currencies; accepts `{ amount: 125050, currency: "BDT" }`
- [ ] `validation`: `paginationQuerySchema` applies defaults, coerces strings, and rejects `limit=0`, `limit=101`, `page=0`
- [ ] Root: `npm run build`, `npm run typecheck`, `npm run test` pass after `rm -rf node_modules && npm install`
