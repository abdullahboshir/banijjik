## Goal
Implement accounting handlers and posting rules for COD cash reconciliation:
1. `courier.settlement.recorded` / `courier.settlement.reversed`:
   - Debits bank/cash/MFS for `netReceived`.
   - Debits `COURIER_FEES` for `courierCharges`.
   - Credits `COURIER_RECEIVABLE` for `grossAmount`.
   - Verifies prerequisite COD payment collection journals exist before clearing receivable.
   - Mirrored reversal on settlement reversal.
2. `delivery.handover.recorded` / `delivery.handover.reversed`:
   - Debits destination cash/bank/MFS for handover `amount`.
   - Credits `RIDER_CASH` asset account.
   - Verifies prerequisite COD collection journals exist.
   - Mirrored reversal on handover reversal.
3. Update `METHOD_ACCOUNT_CODE` to map `COD_COURIER` to `COURIER_RECEIVABLE` and `RIDER_CASH` to `RIDER_CASH`.

## Decisions
1. **System Account Mapping:**
   - When COD payment is received, `METHOD_ACCOUNT_CODE.COD_COURIER` maps to `SYSTEM_ACCOUNT_CODE.COURIER_RECEIVABLE` (Asset).
   - `METHOD_ACCOUNT_CODE.RIDER_CASH` maps to `SYSTEM_ACCOUNT_CODE.RIDER_CASH` (Asset).
   - This records the receivable upon delivery without modifying existing payment posting rules.
2. **Posting Keys & Source Types:**
   - Add `courier_settlement` and `reversal_courier_settlement` to `POSTING_KEY`.
   - Add `rider_handover` and `reversal_rider_handover` to `POSTING_KEY`.
   - Add `COURIER_SETTLEMENT` and `RIDER_HANDOVER` to `JOURNAL_SOURCE_TYPE`.
3. **Ordering Streams:**
   - Courier settlements stream prefix: `courierSettlement:`.
   - Rider handovers stream prefix: `riderHandover:`.
   - Both handlers run as `ORDERED`.
4. **Prerequisite Journal Verification:**
   - Per `4.3-COD.md` line 198: "J2 verifies prerequisite collection journals exist before clearing receivable; a reversal waits for its original posting."
   - For each payment ID, check that a corresponding `sourceType: PAYMENT` journal exists. If not, throw `postingSourceMissing(...)` so the outbox message retries with backoff.
5. **Clean Architecture:**
   - `post-courier-settlements.handler.ts` depends on `CourierSettlementPostingSource` port.
   - `post-rider-handovers.handler.ts` depends on `RiderHandoverPostingSource` port.
   - Concrete adapters implemented in `integration/courier` and `commerce/delivery`.
