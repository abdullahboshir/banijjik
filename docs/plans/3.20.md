# Plan: card 3.20 · Self-hosted fonts

Tier: T3 · Planned by: Opus 5.5 (lead) · Date: 2026-10-23 · Based on commit: `main b1cf16c`

## Session parts
One part, one branch: `s/3.20-local-fonts`. Merge check by the lead.

## Goal
`apps/admin` and `apps/platform` load Inter and Noto Sans Bengali from files in the repository instead of Google Fonts at build time. A CI build no longer fails when Google Fonts is slow or unreachable. This was seen once on 2026-10-23: `Module not found: @vercel/turbopack-next/internal/font/google/font`.

## Inputs read
`apps/admin/app/layout.tsx` and `apps/platform/app/layout.tsx`. Both use `next/font/google`:
- Inter 400/600, latin subset, CSS variable `--font-inter`
- Noto Sans Bengali 400/600, bengali subset, CSS variable `--font-noto-bengali`

## Decisions
1. Use `next/font/local`. It is part of `next`, so there is no new dependency.
2. The font files are woff2, committed per app in `apps/<app>/app/fonts/`. Each app keeps its own folder so the `src` paths stay relative and simple. The four files are small, well under 0.5 MB per app.
   - Files: `inter-latin-400.woff2`, `inter-latin-600.woff2`, `noto-sans-bengali-400.woff2`, `noto-sans-bengali-600.woff2`.
   - Source: the Fontsource builds on jsDelivr, for example `https://cdn.jsdelivr.net/npm/@fontsource/inter@5/files/inter-latin-400-normal.woff2`. Use the same pattern for weight 600 and for `@fontsource/noto-sans-bengali` with the `bengali` subset.
   - Download the files once and commit them. The build never fetches anything.
3. Both fonts use the SIL Open Font License 1.1. Commit `apps/<app>/app/fonts/OFL.txt` with the licence text and one line naming the two families.
4. Keep the current behaviour exactly:
   - the same CSS variables
   - weights 400 and 600
   - `display: "swap"`
   - Inter keeps `preload: false`
   - `adjustFontFallback: "Arial"` for both fonts, because `next/font/local` takes a font name, not `true`
5. Change nothing else: no CSS, no Tailwind config, no new weights.

## Interfaces & types
```ts
import localFont from "next/font/local";

const inter = localFont({
  src: [
    { path: "./fonts/inter-latin-400.woff2", weight: "400", style: "normal" },
    { path: "./fonts/inter-latin-600.woff2", weight: "600", style: "normal" },
  ],
  display: "swap",
  preload: false,
  adjustFontFallback: "Arial",
  variable: "--font-inter",
});
// notoSansBengali: the same shape with the two noto files and variable "--font-noto-bengali"; default preload.
```
