## Goal
The code and the docs say one thing each, in one place:
- duplicated helpers become one kernel or package helper
- files hold one exported concept
- the lint rules the reviews asked for exist
- the docs match the code

## Inputs read
- Review findings M13, M14, M16–M19, M22–M24 and the review's "Doc vs code drift" table (16 rows)
- `05-CONVENTIONS.md` ("Readable code", file naming), ADR-082, ADR-086, ADR-087
- Code paths named in each finding

## Decisions
1. **M16, one helper each** (kernel unless stated):
   - `kernel/db/unit-of-work.ts`: one `withTransaction`-backed `UnitOfWork` implementation; the five module copies become imports.
   - `kernel/db/duplicate-key.ts`: one `isDuplicateKeyError(error, indexName?)`; the six module helpers become imports.
   - `escapeRegExp`, `maskEmail`, `maskPhone` move to `packages/validation` (pure, already used by both API modules).
   - `readTenantCaller` and `clientOf` move to `kernel/access` and `kernel/http`.
2. **M17, app code shared once:** `use-lazy-component.ts`, `get-locale.ts`, the env parsing helper, and the near-identical `i18n-provider.tsx`, `session-renewal.tsx`, `proxy.ts`, `shell-link`, `lazy-toaster`, `language-switch`, `use-locale-change` move to `@banijjik/web-client` (logic) or `@banijjik/ui` (components), parameterized where the two apps differ. Both apps import them.
   - Both browser suites must pass, and both apps' route sizes must stay within ±0.5 KiB (report a table).
3. **M18, one exported concept per file.** Split the 14 multi-concept files of `core/organization` and `platform/*` into one use case, controller or port per file, named as `05` says. This is a mechanical move only: no logic edits, no renames of exported symbols.
   - The convention stays as written in `05` (lead decision: it is the pattern of cards 1.1–1.6 and keeps diffs small).
4. **M19 and the open Phase 0 lint item:**
   - Add the one-line reason comment to the seven casts.
   - New lint rules with fixtures:
     - **R37:** a JSX text node with letters in `apps/**` (user-facing literal text; i18n keys only)
     - **R38:** a property named exactly `id` in object types and interfaces under `**/domain/**` and `packages/contracts/**` (ID naming, ADR-036)
   - A "cast without a comment" rule is not feasible in ESLint without a custom plugin (ADR-082 forbids custom rule logic). Record that in the handoff and keep it a review checklist item.
5. **M22:** `13 §11` says "KiB" where it means kibibytes (`≤ 170 KiB gzip`), matching the tests.
6. **M23 and M24, docs:**
   - Clean the stale STATUS rows the review lists, and use only the status words of the STATUS legend. Add `merged` to the legend if it is kept.
   - Fix the 16 rows of the drift table, each so the doc says what the code does. Any row where the code looks wrong instead → stop and ask, do not change code in this card.
7. **Records:**
   - **M13:** the generated module-off suite covers no production module until the first CORE/OPTIONAL module (Phase 3). That card must check the suite lists it.
   - **M14:** operator management (`/platform/operators`, `14 §7`) becomes card **1.10**, to be done before any SUPPORT or BILLING operator is created. Add the row to STATUS as `todo`.
