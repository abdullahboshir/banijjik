## Goal
Wire the `commission.accrue` handler to:
1. Accrue staff commission for performed order lines on delivery order shipment (`sales.order.shipped`).
2. Deduplicate subsequent reshipment attempts so attempt 2+ does not duplicate commission entries.
3. Fully reverse accrued order line commission when an order is returned to sender (`sales.order.returned`) or closed as delivery loss (`sales.order.lossClosed`).
4. Emit `commission.entry.recorded` on reversals to trigger accounting adjustments.
