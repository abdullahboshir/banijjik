Branch: `s/4.3-cod-b1-shipping-ui`

## Goal

Provide staff operators in the admin dashboard with full UI workflows to manage physical fulfillment for delivery orders:
- Dispatch/ship confirmed or packed delivery orders via courier or own rider (`POST /sales/orders/:orderId/ship`).
- Record failed delivery attempts with reason and note (`POST /sales/orders/:orderId/delivery-attempts`).
- Reship previously failed delivery orders (`POST /sales/orders/:orderId/reship`).
- Receive Return-to-Sender (RTS) with per-line RESTOCK/DAMAGED disposition and manager approval (`POST /sales/orders/:orderId/rts`).
- Reconcile delivery loss with line breakdown (restock, damaged, lost) and manager approval (`POST /sales/orders/:orderId/delivery-loss/close`).
- Recover lost items (`POST /sales/orders/:orderId/delivery-loss/recover`).
- Display delivery attempts timeline/history on the order detail page (`GET /sales/orders/:orderId/delivery-attempts`).

## Decisions

1. **Order Action Flags (`order-action-flags.ts`)**:
   - `canShip`: `permissions.canUpdate && (status === "CONFIRMED" || status === "PACKED") && (method === "COURIER" || method === "OWN_RIDER")`
   - `canFailAttempt`: `permissions.canUpdate && status === "SHIPPED"`
   - `canReship`: `permissions.canUpdate && status === "DELIVERY_FAILED"`
   - `canRts`: `permissions.canUpdate && status === "DELIVERY_FAILED"`
   - `canReconcileLoss`: `permissions.canUpdate && status === "DELIVERY_FAILED"`
   - `canRecoverLoss`: `permissions.canUpdate && status === "DELIVERY_LOSS_CLOSED"`

2. **Action Bar Integration (`order-action-bar.tsx`)**:
   - Add buttons for `Ship`, `Fail Attempt`, `Reship`, `Receive RTS`, `Reconcile Loss`, `Recover Loss` according to flags.
   - Clicking triggers corresponding sheet opening in `order-detail-client.tsx`.

3. **Dialogs & Sheets in `apps/admin/src/sales/fulfillment/`**:
   - `order-ship-sheet.tsx`: Handles both first ship and reship. Inputs: dispatch method (`COURIER` with `consignmentId` or `OWN_RIDER` with `deliveryAssignmentId`).
   - `order-delivery-attempt-sheet.tsx`: Records failed attempt with standard `reasonKey` selector (`CUSTOMER_UNREACHABLE`, `INCORRECT_ADDRESS`, `CUSTOMER_RESCHEDULED`, `CASH_NOT_READY`, `OTHER`) and optional note.
   - `order-rts-sheet.tsx`: Lists shipped lines with quantity selectors and radio/toggle for `RESTOCK` vs `DAMAGED`, reasonKey, and triggers manager approval dialog.
   - `order-delivery-loss-sheet.tsx`: Lists shipped lines with per-line restock, damaged, lost inputs, reasonKey, evidence file IDs, and manager approval dialog.
   - `delivery-attempts-card.tsx`: Renders the list of previous delivery attempts with status, date, and reasons on the order detail page.

4. **API Client (`order-api.ts`)**:
   - Add typed API methods calling `/sales/orders/:orderId/ship`, `delivery-attempts`, `reship`, `rts`, `delivery-loss/close`, `delivery-loss/recover`, and fetching attempts.

5. **Translations**:
   - Add BN and EN translation keys for all fulfillment actions, fields, statuses, and reasons.
