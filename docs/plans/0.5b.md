# Plan: card 0.5b · Admin app skeleton (`apps/admin`)

Tier: T2 · Planned by: Opus 5.5 · Date: 2026-10-10 · Based on: `main 7766e90` + plans 0.4a and 0.5a. **Starts after 0.5a is merged** (needs `@banijjik/ui` and `@banijjik/i18n`). If 0.5a's exported names differ from its plan, refresh this plan first.

## Goal
`apps/admin` is a Next.js App Router app that server-renders the persistent tenant shell of `13 §3` under `/{orgSlug}`. It has:
- the TopBar
- the desktop Sidebar
- the 5-slot mobile BottomNav with Quick create
- the Bangla default locale, with self-hosted Inter + Noto Sans Bengali
- a TanStack Query provider
- a typed API client that sends cookies and understands the `14 §2` envelope

An empty org home scores **Lighthouse mobile ≥ 90**. No `ssr:false` on the shell (ADR-010).

## Decisions
1. **Versions:** Next.js 16 (App Router), React 19, Tailwind v4, `@tanstack/react-query` 5. Check `npm view` at implementation time; use the latest stable of these majors and record it. Turbopack for dev/build is the Next 16 default.
2. **Routes** (one route tree, ADR-004 / `13 §3`):
   - `app/layout.tsx`: the root `<html lang={locale}>`. Fonts via `next/font/google` (`Inter` and `Noto_Sans_Bengali`, `subsets` minimal, `display: "swap"`, CSS variables `--font-sans`); next/font self-hosts them at build time. The global CSS imports `@banijjik/ui/styles.css` + `@source "../../../packages/ui/src"`. `<Providers>` wraps the children.
   - `app/[orgSlug]/(app)/layout.tsx` is a **server component** that renders `AppShell` with TopBar, Sidebar and BottomNav. The org name is the `orgSlug` until 1.7 loads `/me/orgs`. The shell is the layout, so navigation inside an org never remounts it.
   - `app/[orgSlug]/(app)/page.tsx`: Home with `PageHeader` + `EmptyState` (text `home.empty`: "এখনো কিছু চালু করা হয়নি" style key, no action). The empty page is what Lighthouse measures.
   - `app/page.tsx` is **not created**, so `/` is a 404 until card 1.7 adds login. Note it in the handoff.
   - `app/not-found.tsx` and `app/error.tsx` (client) use `EmptyState` with i18n text.
3. **Menu data until 1.6/1.7:** the shell receives `menu: []`.
   - The Sidebar renders no groups.
   - The BottomNav shows **Home**, **[+] Quick create** (with an empty action list → `emptyText`) and **More**.
   - The Work tab and Catalog slots appear only when the resolved config provides them (card 1.7 wires `/me/config`).
   - This is not mock data: the real empty state of an org with no config loaded. Write it in the handoff.
4. **Locale:**
   - `getLocale()` (server) reads cookie `locale` (`bn` default). `getTranslator()` creates the 0.5a translator with that locale, `terms = {}` (org terms come with `/me/config` in 1.7) and `brandName` from env `NEXT_PUBLIC_BRAND_NAME` (ADR-038).
   - Server components call `t()` directly. Client components get strings as props (ui is text-agnostic), or use a small `I18nProvider` context with the same translator for interactive bits (Quick create sheet, toasts).
5. **Providers** (`app/providers.tsx`, client): `QueryClientProvider` with `staleTime: 30_000`, `refetchOnWindowFocus: false`, `retry: (count, error) => count < 2 && !(error instanceof ApiError && error.status < 500)`, plus `<Toaster />` and `I18nProvider`. No React Query devtools in production.
6. **API client** (`src/lib/api/api-client.ts`): `apiFetch<Data>(path, { method, body, idempotencyKey?, signal? })`.
   - Request: base URL from `src/config/env.ts`, `credentials: "include"` (cookies, ADR-010; no tokens in storage), JSON headers, and `Idempotency-Key` when given.
   - On `{ data, meta }` it returns `{ data, meta }`. On `{ error }` it throws `ApiError { status, code, messageKey, details, requestId }`. On a network failure it throws `ApiError` with `code: "INTERNAL"` and `messageKey: "errors.network"` (add that key to the 0.5a catalogs in this card, add-only).
   - Server-side calls (later cards) forward the incoming cookie. Add `serverApiFetch` only when the first server fetch is needed (1.7). Not now.
7. **Env** (`src/config/env.ts`): Zod schema for `NEXT_PUBLIC_API_BASE_URL` (absolute http(s) URL) and `NEXT_PUBLIC_BRAND_NAME` (non-empty), validated at module load. `apps/admin/.env.example` documents both. This is the only file that reads `process.env` (R15 exempts `**/src/config/**`).
8. **Lint:** add `@next/eslint-plugin-next` (`recommended` + `core-web-vitals`) for `apps/admin/**` in `eslint.config.mjs`. Do not change existing rules.
9. **Lighthouse:**
   - `@lhci/cli` in `apps/admin` with `lighthouserc.json`: `collect` runs `next start` on port 3100 and audits `/test-org` with the mobile preset, 3 runs; `assert` sets `categories:performance ≥ 0.9` and `categories:accessibility ≥ 0.9`.
   - Script `lighthouse`. It runs locally now; adding it to CI is a follow-up card note (it needs a Chrome in CI).
   - If Chrome is not available locally, say so honestly.
10. **Package:** `@banijjik/admin`, private. Scripts `dev` (`next dev -p 3000`), `build` (`next build`), `start`, `typecheck` (`tsc --noEmit`), `test` (`vitest run --dir src`), `lighthouse`. Turbo `build` outputs add `.next/**`, `!.next/cache/**` (add-only in `turbo.json`).
11. **PWA, auth, org switcher, `/me/config`:** not in this card (1.7, 3.9).

## Tests (must exist and pass)
- [ ] `apiFetch` sends `credentials: "include"` and the `Idempotency-Key` header when given; parses `{ data, meta }`; throws `ApiError` with `code`, `messageKey` and `requestId` from an error envelope; maps a network failure to `errors.network`
- [ ] `env.ts` rejects a missing or relative `NEXT_PUBLIC_API_BASE_URL`
- [ ] `getLocale` returns `bn` without a cookie, `en` with `locale=en`, and `bn` for an unsupported value
- [ ] `buildBottomNavSlots({ menu: [] })` → Home, Quick create, More. With a config containing orders + catalog entries → 5 slots in the `13 §3` order
- [ ] `next build` succeeds, and the build output shows the `(app)` layout as a server component. Check there is no `ssr: false` anywhere: `grep -rn "ssr: *false" apps/admin` prints nothing.
- [ ] **Lighthouse mobile** on `/test-org`: performance ≥ 90, accessibility ≥ 90 (paste scores)
- [ ] manual: screenshots at 375 px and 1280 px (bn) attached to the handoff, as file paths under `docs/handoffs/assets/0.5b/`
- [ ] all with `--force`: lint, format:check, typecheck, test, build
