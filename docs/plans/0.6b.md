## Goal
The sheets work on phones, the admin API client uses contracts as its single source, CI builds before it lints and really caches the MongoDB binary, and every doc that the review found out of step with the code says what the code does.

## Decisions
1. **J3 sheet stacking:** the sheet's overlay and content must share one layer.
   - In `packages/ui/src/components/sheet.tsx` the overlay uses `z-sheet` and the content `z-sheet` too (the content comes later in DOM order, so it paints above its own overlay). `dialog.tsx` keeps `z-dialog` for both of its parts. Do not change the z-index scale of `13 §8.4`.
   - Add a real-browser check: `apps/admin` gets a small script test `src/shell/sheet-stacking.browser.test.ts` that is run by a new script `test:browser` (headless Chrome through `puppeteer-core`, using the Chrome that Lighthouse already uses; no browser download). It opens `/test-org` at 375 px, opens Quick create and the More sheet, and asserts with `document.elementFromPoint` that the element at the sheet's centre and at its close button belongs to the sheet content.
   - `test:browser` is **not** part of `npm test` (it needs a built app and Chrome); it is documented in the admin README and run in the handoff.
   - Retake `docs/handoffs/assets/0.5b/quick-create-375.png`.
2. **M11 contracts as single source (admin part):**
   - Add to `@banijjik/contracts`: `interface ApiErrorBody { code: ErrorCode; messageKey: string; details?: Readonly<Record<string, unknown>>; requestId: string }`, `interface ApiErrorEnvelope { error: ApiErrorBody }`, `interface ApiSuccessEnvelope<Data, Meta = Readonly<Record<string, unknown>>> { data: Data; meta?: Meta }`.
   - `apps/admin` depends on `@banijjik/contracts`. `ApiError.code` is `ErrorCode`. An unknown code from the wire becomes `ERROR_CODE.INTERNAL` (check with a small `isErrorCode` guard exported from contracts). The local envelope types and the `"INTERNAL"` literals are removed.
   - The API side (typing `sendError` with `ApiErrorBody`) belongs to 0.6a's files, so it is **not** done here; note it in the handoff for the 0.6a merge.
   - `DisplayLocale`/`DigitScript`/`NumberGrouping` move to contracts when the org settings land (card 2.4); leave them and say so in the handoff.
3. **M17:** a 2xx response whose body is missing or has no `data` property → `ApiError` with `code: INTERNAL`, `messageKey: "errors.invalid_response"` (add the key to both catalogs). `204 No Content` is the only exception: `apiFetch` returns `{ data: undefined }` typed through an overload `apiFetch<void>`. Tests for the three cases.
4. **M14 formatting:**
   - `formatNumber` throws `RangeError` for values that are not safe integers (the callers format counts and quantities).
   - `formatMoney` for an unknown currency no longer throws: it formats with 2 fraction digits and the ISO code as the symbol (`USD 12.50`), because a missing symbol must never crash a page. BDT keeps `৳`.
   - Add tests.
5. **M18 empty sidebar:** `AppShell` takes `hasSidebar?: boolean` (default true). When false the sidebar column is not rendered at all (no 256 px gap). The admin layout passes `hasSidebar={menuGroups.length > 0}`. Add i18n keys `nav.primary` and `nav.bottom` (bn/en) and use them as the two landmark labels instead of `shell.openMenu`.
6. **M10 (i18n):** add the reason comment to the cast in `packages/i18n/src/locales.ts`.
7. **M1 CI cache:** move the MongoDB binary cache step **after** `npm ci`. Save it with a key based on the pinned MongoDB version string and the OS (not the lockfile hash), so it survives dependency updates.
8. **M2 CI order:** in the `verify` job run `npx turbo run build --filter="./packages/*"` after `npm ci` and before `npm run lint`, so type-aware lint sees real workspace types. Keep the later full `npm run build`.
9. **M19:** update `docs/ops/github-setup.md`: the dev-only advisory count is no longer 5. State the rule instead of a number: the gate is `npm audit --omit=dev --audit-level=high`; dev-only advisories are reported and reviewed in card 6.3.
10. **Owner decision (2026-10-10) font budget:** `docs/13-UX.md §11` Fonts row becomes "≤ 2 families, subset, ≤ 140 KB total (Noto Sans Bengali is 108 KB on its own; owner decision 2026-10-10)". Add one line under the table: "LCP on the empty shell is 2.9 s under Lighthouse's simulated slow 4G (target 2.5 s). Recheck on a real mid-range phone in card 6.4." Update the 0.5b STATUS note accordingly (remove the font gap, keep the LCP note).
11. **M20 doc drift:** fix every row of the review's "Doc vs code drift" table (14 rows) so the doc states what the code does, **except** where the review marks the code as wrong (none of the 14 does). Rules for the edits:
    - `AGENTS.md` line about global middleware → "Transport middleware (request id, access log, CORS, body parser) is mounted once in `app.ts`. Auth, tenant, entitlement and permission middleware are mounted once in `routes/v1.ts`. Module routers never re-mount them."
    - `[org]` → `[orgSlug]` in `AGENTS.md` and `01`

    - `01 §2`: add `kernel/observability` and `kernel/lifecycle`
    - `05`: `uuidV7Schema`; the contracts pattern is `defineEnum([...])`
    - the remaining rows exactly as the review's table says
    - One commit: `docs: sync phase 0 docs with the code (phase review M20)`.
