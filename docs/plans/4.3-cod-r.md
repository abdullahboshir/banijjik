# Plan: card 4.3 COD R · Own Rider Manual Delivery and Cash Handover

## Session parts
Single part: `s/4.3-cod-r-rider-manual`. Backend API contracts, validation, domain entities, delivery module, tenant routes, and integration tests.

## Goal
Enables manual own-rider assignment, status tracking, and cash handover reconciliation for orders with `fulfillmentMethod: "OWN_RIDER"`. Staff can assign a rider (who is an active organization member at the order's location), optionally triggering order shipment with `OWN_RIDER` dispatch; record cash handovers from rider to staff with gross amount verification, ensuring staff cannot approve their own handover; and reverse handovers via approval token.

## Decisions

1. **Module Placement:** `apps/api/src/modules/commerce/delivery`.
   - Core module declared with `MODULE_CLASS.CORE`, key `delivery`.
   - Dependencies: `sales`, `payment`.
   - Requires kinds: `PRODUCT`.
2. **DeliveryAssignment Aggregate:**
   - Identity: `deliveryAssignmentId` (UUIDv7 via `newId()`).
   - Fields: `organizationId`, `locationId`, `orderId`, `riderMemberId`, `attemptOrdinal`, `status` (`ASSIGNED`, `IN_TRANSIT`, `DELIVERED`, `FAILED`, `CANCELLED`), `notes`, `version`, audit timestamps/actors.
   - Assignment requires order `fulfillment.method === "OWN_RIDER"`.
   - If `shipOrder: true` (default `true`), calls order shipping port with `{ method: "OWN_RIDER", deliveryAssignmentId }`.
3. **RiderCashHandover Aggregate:**
   - Identity: `riderCashHandoverId` (UUIDv7 via `newId()`).
   - Fields: `organizationId`, `locationId`, `riderMemberId`, `receivedByMemberId` (derived from authenticated staff, must NOT equal `riderMemberId`), `paymentIds`, `amount` (`Money`), `receivedVia` (`CASH`, `BANK`, `BKASH`, `NAGAD`), `posSessionId` (optional), `businessDate`, `reversesRiderCashHandoverId` (null or previous ID), `reversalReason`, `version`, audit timestamps/actors.
   - Guard: Rider cannot approve their own handover (`riderMemberId !== receivedByMemberId`).
   - Guard: Payments must belong to organization, currency must match, and gross amount must equal sum of payment amounts.
4. **Approval-gated Reversal:**
   - `POST /delivery/handovers/:id/reverse` requires approval token with action `APPROVAL_ACTION.RIDER_HANDOVER_REVERSAL`.
   - Single reversal per handover enforced by unique partial index `{ organizationId: 1, reversesRiderCashHandoverId: 1 }`.
5. **Permissions:**
   - `DELIVERY_ASSIGNMENT_CREATE`: `delivery.assignment.create`
   - `DELIVERY_ASSIGNMENT_READ`: `delivery.assignment.read`
   - `DELIVERY_HANDOVER_RECORD`: `delivery.handover.record`
   - `DELIVERY_HANDOVER_REVERSE`: `delivery.handover.reverse`
   - Assigned to `OWNER`, `ADMIN`, `MANAGER` system roles.
6. **Events:**
   - `delivery.assignment.created`
   - `delivery.handover.recorded`
   - `delivery.handover.reversed`
7. **Audit Actions:**
   - `delivery.assignment.created`
   - `delivery.handover.recorded`
   - `delivery.handover.reversed`
