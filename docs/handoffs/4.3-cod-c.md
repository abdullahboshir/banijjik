2. **Integration Module (`apps/api/src/modules/integration/courier`):**
   - **Domain Layer:**
     - `consignment.entity.ts`: Domain aggregate for Consignment with `attemptOrdinal`, immutable tracking info, and UUIDv7 identity.
     - `courier-settlement.entity.ts`: Domain aggregate for CourierSettlement enforcing `courierCharges <= grossAmount`, net received calculation, and reversal immutability.
     - `courier-repository.ts`: Repository interfaces for Consignments and Settlements.
     - `errors.ts`: Domain errors (`duplicateTrackingNumber`, `settlementChargesExceedGross`, etc.).
   - **Infrastructure Layer:**
     - `courier.schema.ts`: Mongoose schemas with compound indexes (`organizationId + trackingNumber`, `organizationId + externalReference`, `organizationId + reversesCourierSettlementId` with partial index filter).
     - `mongo-courier.repository.ts`: Mongo repository implementations respecting sessions, tenant isolation, and versioning.
   - **Application Layer:**
     - `CreateConsignmentUseCase`: Verifies order exists, matches fulfillment method `COURIER`, checks tracking number uniqueness, assigns attempt ordinal, creates consignment aggregate, optionally dispatches `shipOrder`, emits `courier.consignment.created`, and records audit.
     - `ListConsignmentsUseCase`: Paginated query with location and courier key filtering.
     - `RecordCourierSettlementUseCase`: Verifies payments belong to organization, enforces single currency, computes gross, ensures courier charges $\le$ gross, inserts settlement, publishes `courier.settlement.recorded`, and records audit.
     - `ReverseCourierSettlementUseCase`: Verifies settlement exists, checks not already reversed, verifies approval token via `ApprovalVerifier.consume` inside UoW, inserts reversal settlement record with `reversesCourierSettlementId`, publishes `courier.settlement.reversed`, and records audit.
   - **Presentation Layer:**
     - `courier-tenant.router.ts`: Mounted tenant router with permission checks, request validation, and idempotency headers.
     - `courier.manifest.ts`: Module manifest declaring CORE class, dependencies (`sales`, `payment`), permissions, and settings.
