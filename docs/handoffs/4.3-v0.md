## Built

- `apps/storefront/src/api/client-api.ts`: `ClientResult.errorCode` (D1), filled from `error.code` of a non-2xx envelope.
- `apps/storefront/src/checkout/checkout-outcome.ts` (new): `SUBMIT_OUTCOME`, `submitOutcomeOf`, `isMissingSession`, `quoteErrorKeyOf` (D4, D5). All decisions use `errorCode` compared with `ERROR_CODE.*`.
- `apps/storefront/src/checkout/checkout-api.ts`: `requestQuote` creates a guest session once after a 401 `UNAUTHENTICATED` / `WEBSITE_GUEST_SESSION_EXPIRED`, quotes once more, and returns the session's own refusal when session creation fails (D2).
- `apps/storefront/src/checkout/checkout-view.tsx`: submit no longer calls `createGuestSession` (D3); outcome mapping per D4 (`SESSION_LOST` reuses the quote-expired alert); refreshed-quote error uses `quoteErrorKeyOf` (D5).
- `apps/storefront/src/checkout/cart-view.tsx`: quote error uses `quoteErrorKeyOf` only (D5). No `useMemo`.
- `apps/storefront/src/i18n/client-translator.ts`: module-level `Map<Locale, Translator>` cache (D6).
- `packages/i18n/src/catalogs/storefront/{en,bn}.json`: `storefront.cart.guestCheckoutDisabled`, `storefront.checkout.capacityUnavailable` (BN and EN, same order).
- `apps/storefront/src/commerce.browser.test.ts` (new, D7): taken from V; price change runs at 360 px (`DESKTOP_VIEWPORT` removed); `clickButton` uses `page.click('button::-p-text("...")')`; golden path reloads the receipt and asserts `cache-control` contains `no-store`; new case "recovers when the guest session is lost between quote and submit" (uses `context.deleteMatchingCookies`, because the page-level cookie API is deprecated in puppeteer-core 24).
