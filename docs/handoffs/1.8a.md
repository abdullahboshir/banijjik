## Review fixes (Opus review, 2026-10-11)
- **Archive vs change-package:** `Package.referenceVersion` guard counter. Change-package writes every named package inside its transaction (`touchActive`, leaves `version` and `updatedAt` alone); a matched count below the number named is `PACKAGE_KIND_MISMATCH`. Archive now checks usage inside its transaction and writes the same document, so a concurrent pair conflicts and the retry validates again. Test `package-archive-race.test.ts`: 10 concurrent pairs, 3 rounds, no subscription ends on an ARCHIVED package. One sentence added to ADR-093.
- **One diff helper:** `kernel/audit/audit-diff.ts` only. The two copies behaved the same; `core/organization` now imports `diffAuditFields` and `AuditFields` from the kernel, and its `audit-diff.ts` keeps only `assignmentsAuditValue` (not a duplicate).
- **`GET /platform/me`:** behind `authenticatePlatform`, answers `PlatformMeResponse` (= the login answer shape); test in `platform-auth-api.test.ts`; row in `14-API.md` section 7.
- **Package display name:** `nameKey` (seed) or `name` (operator-made, 2 to 60 characters), never both. Create requires `name`; patch may rename only operator-made packages; responses carry both (one null). `09 section 4.6` updated.
- **Gaps closed:** the write-skew and the display-name gaps above no longer apply; `GET /platform/me` exists.
- **Verification note:** the api task needs `VITEST_MAX_WORKERS=2` on a low-memory machine (set in the environment, config defaults unchanged).
