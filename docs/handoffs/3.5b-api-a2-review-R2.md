## Lead fixes on the branch
1. **The mirror journals were back-dated to the return's business date.** A return on day 1 reversed on day 20 changed day 1's books and reports. The reversal now stores `reversal.businessDate` (the organization's local date of `reversedAt`), the posting snapshot carries it as `reversalBusinessDate`, and the handler dates both mirror journals on it (a reversed event without it is a missing posting source). The test `the reversal posts the mirror of both return journals once, also on event replay` now reverses on a later day and checks the journal date.
2. `storedUnitCost` narrowed the stored currency with `stored !== CURRENCY_CODE.BDT`, which assumes one currency. It now compares with the organization currency and narrows with a type guard over `CURRENCY_CODE` values.
