## Deviations from the plan (and why)
1. **S3 driver uses `@aws-sdk/client-s3`.** The plan allowed only `sharp` and `busboy` as new dependencies but needs an S3-compatible driver. Owner chose the SDK when asked. Also added `@types/busboy` (dev).
2. **File contracts are exported from `@banijjik/contracts/file`, not the root index.** `packages/contracts/src/index.ts` is exactly at the 300-line lint cap, so nothing fits. Owner chose a subpath export. Consequence: `package.json` `exports` gained `./file`, and the domain lint rule (`eslint/restrictions.mjs`, `DOMAIN_FORBIDDEN_SOURCE`) now also allows `@banijjik/contracts/file`. Later cards that also hit the cap can follow the same way, or the index needs a planned split.
3. **New error codes `PAYLOAD_TOO_LARGE` (413) and `UNSUPPORTED_MEDIA_TYPE` (415)** in contracts and `14-API.md` section 3. The plan names these statuses but the code set had no entry for them.
4. **Probe module key changed.** `KERNEL_PROBE_MANIFEST` squatted `MODULE_KEY.FILE` "until that module arrives". It now uses `MODULE_KEY.AI`. Harness gained a `fileOverrides` option.
5. **`routes/v1.ts` hit the lint size limits.** `buildOrganizationTenant` moved to the new `routes/organization-tenant-routers.ts` and the core routers are built in a helper, with no behaviour change. The core routers are built before the tenant router is mounted so the public router can be mounted outside the tenant pipeline.
6. **Admin read-only detail list** now shows "Uploaded" for a saved image or file (it showed nothing before). Small, and without it a saved image looked like "no value".
7. **Public route has no rate limit** and **no virus scan** (see gaps).
