- **Deviations from plan (and why):**
  1. **`/me/config` does not carry bot tools, storefront sections or custom-field entities** (its response has modules, kinds, limits, menu, terms, settings, permissions). Assertions 3 to 5 read those lists from the resolved config of `OrgConfigService.forOrganization`, the service the gate uses; assertion 2 and the module list read `/me/config`.
  2. **`PLATFORM_REVOKE` and `TENANT_DISABLE` are skipped for CORE modules** (and for "not in package"). The resolver adds every CORE module to the candidates whatever a package or override says (`10 §3` step 2), so those paths cannot turn a CORE module off. This is the open question 1.6a already raised about CORE modules marked tenant-disableable in `10 §5`. CORE modules are still turned off by template, missing kind and missing dependency.
  3. **Three probe modules, not two.** `workflow` needs a real OPTIONAL dependency to exercise "dependency missing"; `website` is it, and `catalog` is the CORE module that also provides the PRODUCT kind that `workflow` requires. Probe keys are catalogue keys no real module uses yet; change them when that module arrives (same note as the 1.6a probes).
  4. **`templateReader?` option on `V1Dependencies`** (and on `startIamApi`). The suite needs to change the industry template (module excluded, kind missing) and `buildV1Router` built the interim reader itself. Add-only, test seam of the same kind as `extraManifests`; production passes none. The gate and the resolver are untouched.
  5. **Signature:** `describeModuleContracts({ registry, productionKeys, harness: () => harness, templateReader, moduleData, organizationFields })`. The harness is a function because it starts in `beforeAll`, after the tests are declared; `organizationFields` carries the industry template key because lint R16 keeps that literal in `*.test.ts`.

  7. **Router walk instead of the registry fallback:** the Express 5 stack is readable for route layers and path-less mounts (found by asking each layer whether it matches a tenant path), so the primary method of the plan was used.
