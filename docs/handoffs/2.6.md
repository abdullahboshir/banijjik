- Add one lint fixture: a file under `apps/platform/src/industry-templates/` that compares the key **fails**; one that only names it **passes**.
- Record the scope in ADR-106 in one sentence.
- Next time a lint scope needs to change, stop and ask first (`docs/ops/implement-with-cursor.md`: never weaken a rule to make code pass).
