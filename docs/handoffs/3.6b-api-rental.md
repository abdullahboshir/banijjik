# Handoff: card 3.6b, Part A1 · Rental Bookings (API)

Implemented by: Antigravity (Sonnet) · Date: 2026-10-23 · Plan: `docs/plans/3.6b.md` (and Refresh 2026-10-23) · Branch: `s/3.6b-api-rental` · Tier: T1

## What was built
- **Contracts (`@banijjik/contracts/booking`):**
  - Added `BOOKING_COMPLETE_GRACE_MINUTES_SETTING_KEY = "booking.completeGraceMinutes"`, `BOOKING_COMPLETE_GRACE_MINUTES_DEFAULT = 60`.
  - Added helper `isRentalBookingKind(kind)`.
  - Added rental error rule keys to `BOOKING_RULE_KEY` and `BOOKING_MESSAGE_KEY`:
    - `BOOKING_RENTAL_UNITS_OUT_OF_RANGE = "BOOKING_RENTAL_UNITS_OUT_OF_RANGE"`
    - `BOOKING_RENTAL_DURATION_EXCEEDED = "BOOKING_RENTAL_DURATION_EXCEEDED"`
  - Re-exported new symbols in `packages/contracts/src/booking/index.ts` (added lines only).
- **Validation (`@banijjik/validation/booking`):**
  - Updated `bookingCreateRequestSchema` to accept optional `quantity: z.number().int().positive().optional()`.
- **Domain (`apps/api/src/modules/commerce/booking/domain`):**
  - Added `rental-time.ts` with `computeRentalTime`:
    - Handles rate units `HOUR`, `DAY` (DST-safe local date calculation via calendar days in organization timezone), and `NIGHT` (snaps to `checkInTime` default 14:00 and `checkOutTime` default 11:00).
    - Enforces units validation `minUnits <= quantity <= maxUnits` (`BOOKING_RENTAL_UNITS_OUT_OF_RANGE`).
    - Enforces hard 31-day duration cap (`BOOKING_RENTAL_DURATION_EXCEEDED`).
    - Unit tests in `rental-time.test.ts` (11 tests covering HOUR, DAY, NIGHT, min/max units, 31-day cap, 32-day rejection, and DST transitions across Fall-back and Spring-forward).
  - Updated `Booking.createStaff` and `Booking.createHold` in `booking.entity.ts` to accept optional `kind` (`BookingKind`) and `quantity` (defaulting to 1).
- **Application & Ports (`apps/api/src/modules/commerce/booking/application`):**
  - `BookingOfferingReader.readOffering` updated to return `OfferingBookingView` supporting both `SERVICE` and `RENTAL` (`RentalOfferingView`).
  - `BookingSettings` includes `completeGraceMinutes: number` (default 60).
  - `PriceQuoterPort.quote` accepts `quantity?: number | undefined`.
  - `quoteDepositForBooking`: when rental `kindDetails.depositAmount` is present, it overrides percentage calculation and uses the explicit minor-unit amount.
  - `prepareStaffBooking`, `prepareHoldBooking`, and `CreateBookingAttempt` calculate booking times via `computeRentalTime` for rentals.
  - `reschedule-booking.use-case.ts` recalculates rental times when rescheduling rental bookings.
  - `listActiveForOffering` in `ResourceRepository` accepts optional `resourceTypeKeys?: readonly string[] | undefined`.
  - In `booking-slot-selection.ts`, rental resources skip daily business-hours schedule checks because rentals span multiple days/nights outside single-day opening schedules.
- **Auto-Complete Scheduled Job (`auto-complete.job.ts`):**
  - Added scheduled background job `booking.autoComplete` registered via `kernel/jobs` (every 5 minutes).
  - Queries `CHECKED_IN` rental bookings where `endsAt + graceMinutes <= clock.now()`.
  - Transitions them idempotently to `COMPLETED` in a transaction with audit logs, skipping already-modified rows.
- **Module Manifest & Worker Registration:**
  - Added `OFFERING_KIND.RENTAL` to `bookingManifest.providesKinds`.
  - Registered `booking.completeGraceMinutes` setting in `bookingManifest.settings`.
  - Registered `buildAutoCompleteJob` in booking scheduled jobs, wired into `start-worker.ts` (passing `audit`).
  - Added router support in `routes/booking-tenant-router.ts` passing `quantity: payload.quantity ?? 1` to price quoter.
