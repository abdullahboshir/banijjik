   (contact module index): find-or-create by E.164 phone, active-contact check. `contact/index.ts`
   exports it; `booking-schemas.ts` contact-link uses the shared `contactLinkCreateSchema`;
   new API specs `booking-contact-inline-api.test.ts` (3).

   copy with `contactLinkCreateSchema` from `custom-field/contact-link-input.js`, keeping the
   3.1b ADR-073 `{ name, phone }` pattern as one source for hold and create.

   resourceTimeOff and the action regex aligned to the shared event-name pattern
   (ADR-122 names kept; renaming them would have churned contracts).

   then worker/queue/redis/databases; asserted by `start-worker.test.ts`.

   "Functions cannot be passed directly to Client Components"): `weekdayLabel` (resource sheet)
   and `statusLabel` (booking calendar) now come from `useTranslator()` inside the client
   component, the pattern the rest of the repo already uses.

   "স্লট বুক করুন" sets the seed AND bumps `bookingSheetReveal`; `LazySheetButton` gains an
   optional `revealSignal` counter prop (settings shared component, additive only).

   (`seedBookableService`, `publishTemplate`) to keep `browser-stack.ts` under the `max-lines`
   rule; `publishTemplate` marks the seeded SALON template PUBLISHED (signup needs it, ADR-075);
   `catalog-screens.browser.test.ts` imports it.

   flight, so `slotCount` now watches the settled `/availability` response and then the buttons
   it produced. Before this, the same test passed and failed run to run nondeterministically.
