## What was checked
- **Instant path only (decision 1):** `allowedKinds` is required on `quoteAndPrepare` and `prepareOrderLines`; create, place and update pass `[PRODUCT]`; only `InstantOrderUseCase` passes `[PRODUCT, SERVICE]`. POS sales and the exchange's new order reach it through `InstantSaleService`; no other caller exists (`git grep quoteAndPrepare`).
- **Effective kind (decision 3):** the instant path intersects with `SalesKindReader.effectiveKinds`, wired from the request's `orgConfig` (ADR-033; no `industry` read). Test: `a SERVICE line is refused when SERVICE is not an effective kind`.
- **No stock, no slot (decisions 2, 4):** a SERVICE line gets `costComponents: []` and no tracked or cost line even when the document carries stock components (the first API test plants components on purpose). Nothing touches bookings or `resource_slot_usages` (test `a walk-in service holds no slot`).
- **Quantity (decision 5, A-1):** the request schema already requires an integer quantity; the test asserts `validation.invalid_type` at `lines.0.quantity`.
- **Books (decision 7):** the pricing quote sets `discountTotal = Σ lineDiscount` and `grandTotal = Σ lineNetTotal + rounding`, so `Σ_SERVICE (lineNetTotal + lineDiscount − lineTax)` is the per-line part of `goodsAmount` for tax-inclusive and exclusive prices alike. The split keeps one balanced `order_revenue` journal and refuses service goods above the goods total or in another currency (`INTERNAL`). Unit and worker-path tests cover it.
- **Commission and returns (decisions 6, 8):** the SERVICE rule accrues 10 % and a one-unit return reverses half; a returned service line writes no movement; an exchange can sell a service.
- **Till snapshot (decision 9):** PRODUCT and SERVICE, active only on a full read; the delta path keeps its removal handling.
- **Tenancy and permission:** cross-org service refused with no order written; a member without `sales.order.create` gets 403.
- Docs: `11 §5.3`, ADR-044 note, sales README (30 lines) updated. No new contract key, so count tests are unchanged.
