## Deviation from plan (needs the Opus review)
- Mongoose's `buildMiddlewareFilter` keeps any hook marked with `Symbol.for("mongoose:built-in-middleware")` running under `middleware: false`. The plan said a hook cannot catch the option, which is true only for unmarked hooks. I marked the tenant, location and append-only hooks (`kernel/db/unskippable-hook.ts`) **in addition to** the plan's wrapper. Reason: the wrapper checks options at call time, so `const run = q.exec(); q.options.middleware = false` is a time-of-check gap; the marking closes it at the root. Tests go around the wrapper (base `Query`/`Aggregate` prototypes) and prove the hooks hold; with the marking disabled those 5 tests fail. The reviewer may drop the wrapper or keep both.
- Lint J3 and R36 share one commit (they edit the same new file `eslint/bypass-restrictions.mjs`); the run-as-system, request-context, raw-collection and new middleware blocks moved there because `restrictions.mjs` hit the 300-line cap.
- The R26 fixture `platform/demo/application/r26-run-as-system-in-platform-application.pass.ts` was renamed to `...-in-unlisted-platform-application.fail.ts` and now expects the two errors: the exemption it tested no longer exists (plan decision 4). Its expectation is the only existing assertion changed.
- New small files: `register-all-models.ts` (one list shared by `main.ts` and the sync entry), `kernel/db/index-sync.ts`, `seeds/run-sync-indexes.ts`, `test-support/spawned-process.ts` (new spawn helper; `main.test.ts` was left untouched so its helpers are duplicated).
- Index audit uses Mongoose `diffIndexes` (compares keys, unique, partialFilterExpression, sparse, expireAfterSeconds, collation), a superset of the plan's list.
