Put the rules into the update filter too: `seatsSold: { $lte: newCapacity }`, and `seatsSold: 0` when the time changes. A miss there answers the same 422 rule error (not 409). Test: set `seatsSold` directly in Mongo after the read (or between two calls) and check the update is refused.
