## 1. Scope & Verification

All production and test files planned in Refresh C1-1 were verified against the plan's requirements, architectural ADRs, and the T1 review checklists:
- `STOREFRONT_RESERVED_HOSTNAMES` is enforced in production with validation rejecting schemes, ports, and empty entries; development/test defaults safely to an empty array.
- Host claim lookup in `operations` resolves global routing; tenant website and site reads execute strictly within `runInOrganizationContext`. Inactive organizations and organizations lacking the `WEBSITE` module return 404 (`errors.storefront_not_available`). Authoritative lookup failures return 503 (`RETRY_LATER`) with `no-store` and `Retry-After: 1`, never 404.
- Spoofed client headers (`x-storefront-organization-id`, `x-forwarded-host`) are removed or overwritten with trusted values.
- Combined LRU cache is bounded at 2,000 entries, caches unknown hosts negative for at most 30 seconds, and never positively caches eligibility.
