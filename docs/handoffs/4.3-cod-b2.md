## Summary
Implemented administrative screens, forms, and approval flows for courier settlement, rider cash handover, and sensitive reversal operations.

### Deliverables:
- **BN/EN Catalogs (`packages/i18n`):** Added keys for courier consignments, courier settlements, delivery assignments, and rider cash handovers with reversal and confirmation labels.
- **Courier Management UI (`apps/admin/src/courier/`):**
  - `courier-api.ts`: Typed API client for `listConsignments`, `createConsignment`, `recordCourierSettlement`, and `reverseCourierSettlement`.
  - `courier-consignments-screen.tsx`: Consignments list table with courier filtering (`STEADFAST`, `PATHAO`, `REDX`, `PAPERFLY`, `OTHER`), status tags, timestamps, and "Record settlement" action trigger.
  - `courier-settlement-sheet.tsx`: Form sheet to record courier settlements with external reference, courier fee/charge, receivedVia (`CASH`, `BANK`, `BKASH`, `NAGAD`), businessDate, and multiple payment IDs.
  - `courier-settlement-reverse-dialog.tsx`: Dual-control manager PIN approval dialog requesting `APPROVAL_ACTION.COURIER_SETTLEMENT_REVERSAL` before executing settlement reversal.
- **Delivery & Rider Handover UI (`apps/admin/src/delivery/`):**
  - `delivery-api.ts`: Typed API client for `listDeliveryAssignments`, `createDeliveryAssignment`, `recordRiderCashHandover`, and `reverseRiderCashHandover`.
  - `delivery-assignments-screen.tsx`: Delivery assignments table with status filtering, rider member ID, attempt ordinal, notes, timestamps, and "Record cash handover" action trigger.
  - `rider-handover-sheet.tsx`: Form sheet to record rider cash handover with rider member ID, receivedVia, businessDate, optional posSessionId, and multiple payment IDs.
  - `rider-handover-reverse-dialog.tsx`: Dual-control manager PIN approval dialog requesting `APPROVAL_ACTION.RIDER_HANDOVER_REVERSAL` before executing handover reversal.
