## 1. Blockers (must be fixed before V merges)

1. **B1 · "dispatches the real outbox" is not what the test proves.** The name at `storefront-commerce-scenarios.test.ts:462` and handoff bullet 1 claim real outbox + worker; the run above shows an unasserted recording queue and zero consumers. The fix must (a) assert the enqueued jobs (id/type/payload shape) or run the real handler chain for an event that has a consumer, (b) prove the row is claimed by *this* org and not merely counted, and (c) keep the `DISPATCHED` read-back. A test that passes when a different organization's event is dispatched is not a verification test.
2. **B2 · the unpaid-hold expiry never goes through the worker.** `:664` names "once through the real worker", `:752-759` calls the job directly. Fix by running the expiry through the worker/queue path (the same entry the production worker uses), and prove "once": a second dispatch must not release the slot twice, must not double-write, and the released capacity must be read back. AGENTS.md forbids presenting a direct call as the worker.
