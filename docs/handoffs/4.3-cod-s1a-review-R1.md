That proves A cannot read B’s row; it does not prove the tenant plugin would hide a leaked id queried as the owner org from another ALS context. Production use cases pass the authenticated org. 5. **`markFailed` throws `INVALID_TRANSITION` with `currentStatus: "FAILED"`**, which is not an `ORDER_STATUS`. S1f can keep or replace when wiring order transitions.
6. **Handoff omits `npm run card:check`.** Entry ticket for *merge*, not a code defect.
