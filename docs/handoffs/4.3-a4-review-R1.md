## 2. Invariant & Architecture Checklist

- [x] **Storefront Idempotency:** Uses `IDEMPOTENCY_SCOPE_KIND.STOREFRONT` namespace scoped to `[principalType, organizationId, principalId].join(":")`.
- [x] **Replay Authorization Guard:** Replay is authorized against `CheckoutAccess` aggregate before returning cached response, preventing revoked or foreign principals from observing checkouts.
- [x] **Pricing & Source Invariants:** Pricing, discounts, taxes, and source cannot be injected by client; all prices re-verified at submission time against catalog quote reader.
- [x] **No Multi-Org / Cross-Org Leaks:** Organization boundary enforced at database query level and checked against caller.
- [x] **Quote Expiry & Re-Quote:** Quotes strictly expire in 5 minutes; submitting an expired quote returns `CHECKOUT_QUOTE_EXPIRED`.
- [x] **Rate Limiting:** 10 checkouts per 10 minutes enforced on `POST /checkout`.
- [x] **Code Quality:**
  - Zero TODOs, stubs, or mock data presented as finished code.
  - All files strictly <= 300 counted lines.
  - Functions <= 60 lines, nesting depth <= 3, cyclomatic complexity <= 10.
  - No `any`, clean TypeScript and ESLint.
