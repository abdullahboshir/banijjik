## What was built
- **Menu entry** (`apps/api/src/modules/commerce/report/module.manifest.ts`): one entry `report.daily` in group `reports`, path `reports`, icon `chart-column`, permission `report.daily.read`, label `menu.report.daily`. The report module stays CORE and not disableable.
- **i18n** (`packages/i18n/src/catalogs/screens/en.json`, `bn.json`, add-only): 45 keys each, `menu.report.daily`, `report.home.*`, `report.page.*`.
- **Home** (`apps/admin/app/[orgSlug]/(app)/page.tsx` now calls `ReportHomePage`): the greeting always; with `report.home.read` the API's home response draws one card per section it returns (Sales, Bookings, Enrollments, Money). Each row shows today, with yesterday and this month so far under it. The location filter is a plain GET form (`?location=`) and appears only when the caller has more than one location. A new business sees one empty note. A caller without the permission, or a home read the API refuses, sees the greeting only.
- **Reports page** (`apps/admin/app/[orgSlug]/(app)/reports/page.tsx`): `?from=&to=&location=`, default the last 7 business days up to today (the organization time zone). A range the API would refuse falls back to the default. Table of the days with a totals row from md; one card per day plus a totals card below md. One hand-made SVG bar chart of net sales after returns per day (no chart library). A CSV button builds the file in the browser from the shown rows.
- **Pure helpers** (`apps/admin/src/report/`): `report-dates.ts`, `report-query.ts`, `report-figures.ts`, `report-home-cards.ts`, `report-locations.ts`, `report-csv.ts`, `report-format.ts`. Money goes through the shared `formatMoney`.
- **Server loaders** (`report-server-data.ts`, `server-only`): the home read, the daily read and the location list, all through the existing server resource helpers.
- **Screens**: `report-home-page.tsx`, `report-home-view.tsx`, `report-daily-page.tsx`, `report-daily-filter.tsx`, `report-daily-table.tsx`, `report-bar-chart.tsx`, `report-csv-button.tsx` (the only client component).

## Deviations from the plan (with reasons)
1. **CSV money is integer minor units**, not the formatted text on screen. The CSV is meant for a spreadsheet, and the locale formatter writes Bengali digits and a currency symbol. The header names are unchanged, so the file has no unit column. The owner may want a units note: a follow-up.
2. **Chart: a negative day draws no bar.** Net sales after returns below zero needs more returns than sales in one day. The table still shows the figure. The chart does not draw below the zero line.
3. **Permission for the filter.** The location filter reads the caller's locations from `permissions` (all locations, or the locations with the permission), not from a separate endpoint. Only the location list is read from the API.
4. **Home subtitle** keeps the existing `home.ready` text.
