# 3.21 Organization currency in accounting and bookkeeping (handoff)

Implemented by Sonnet 5.5 against `docs/plans/3.21.md` including Amendment 1. API only, T2.

## What was built
- `accounting/application/organization-currency.ts`: `OrganizationCurrencyPort` and `requireOrganizationCurrency` (a missing currency throws `ERROR_CODE.INTERNAL`, never a literal).
- Use cases `get-trial-balance`, `balance-sheet`, `profit-and-loss`, `list-bookkeeping-accounts` take the port and the organization id; `post-manual-entry` (`consumeJournalApproval`, shared with reversal) reads the currency for the approval amount.
- The trial balance always uses the organization currency, not the first entry's.
- Controllers pass `readTenantCaller().organizationId`; `bookkeeping/index.ts` passes its existing `currencies`; `accounting/index.ts` adds `currencies` to `AccountingTenantDependencies`; `routes/accounting-tenant-router.ts` wires `buildOrganizationCurrencyReader()`.
- A2: deleted the unused `JournalEntry.debitTotal()/creditTotal()`; `mongo-journal.repository.ts` casts to `Money["currency"]`.
- `git grep -n '"BDT"'` in accounting and bookkeeping finds test files only.

## Deviations (approved by the lead, Amendment 1)
- New shared helper `accounting/application/organization-currency.ts`.
- `ListBookkeepingAccountsUseCase` takes a dependencies object (lint: at most 3 constructor parameters).
- `GetTrialBalanceUseCase.execute(organizationId, asOf)` signature; `posting-engine.test.ts` call updated (still BDT).
- A1: the USD approval-token HTTP test was dropped (`CURRENCY_CODE` is BDT-only); replaced by unit tests. The `approvalFor` helper change was not needed and was not kept.

## Tests
- `bookkeeping-api.test.ts`, "organization currency in bookkeeping": `answers the trial balance in the organization currency, also with no entries`; `answers the account list, profit and loss and balance sheet in the organization currency` (organization A set to USD in the raw collection).
- `post-manual-entry.use-case.test.ts`: `consumes the approval with the amount in the organization's currency`; `refuses with INTERNAL when the organization has no currency`.
- Existing BDT, permission-denied and cross-org tests unchanged and green.
