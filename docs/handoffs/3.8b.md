### 4. Bookkeeping Module (apps/api/src/modules/commerce/bookkeeping)
**Domain layer:**
- `domain/errors.ts`: Bookkeeping-specific errors (systemAccountLocked, accountArchived, entryAlreadyReversed, futureBusinessDate)

**Application layer (use cases):**
- `create-account.use-case.ts`: Creates custom accounts with `C-<n>` codes
- `update-account.use-case.ts`: Updates account name or status (system accounts locked)
- `post-manual-entry.use-case.ts`: Posts manual journal entries with validation
- `reverse-entry.use-case.ts`: Reverses journal entries (manual or automatic)
- `profit-and-loss.use-case.ts`: Generates P&L statement by account type
- `balance-sheet.use-case.ts`: Generates balance sheet with equity/retained earnings

**Presentation layer:**
- `bookkeeping.controller.ts`: Controllers for all endpoints
- `bookkeeping-tenant.router.ts`: Tenant routes with permissions

**Module manifest:**
- `module.manifest.ts`: OPTIONAL add-on, depends on ACCOUNTING
- Routes: accounts, journal/manual, journal/:id/reverse, statements/*
- Menu: accounts, journal, statements (group "money")
- Settings: bookkeeping.manualEntryOwnerWithoutApproval (default true)
- No custom fields, bot tools, or storefront sections

**Index:**
- `index.ts`: Builds router with all use cases
