# Handoff: 3.37 payment browser test booking time (lead card)

- **Problem:** `apps/admin/src/payments/payment-screens.browser.test.ts` booked the salon service at `Date.now() + 24 h`. The stylist is open 00:00–23:59 every day, so on runs near Dhaka midnight the service ended after closing and the API answered `409 SLOT_UNAVAILABLE` in `beforeAll` (CI 40216646977 on the 3.5b A3 docs commit, rerun failed too; CI 40217669280 on M.6c). Every branch failed in that window.
- **Fix:** `tomorrowMorningInDhaka()` takes today's Dhaka date (like `nextMonday()` from 3.17) and books tomorrow 10:00 Dhaka. Checked with runner times 03:00, 17:50 and 18:30 UTC: always a future 10:00 Dhaka, at least 10 hours ahead.
- **Tests:** only this test file changes; no expectation changed. The CI browser suite on this branch is the check.
- **Not done:** other browser tests that use `Date.now()` for bookings were not searched in this card.
