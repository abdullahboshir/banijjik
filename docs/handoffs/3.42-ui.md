## Implemented

- Held carts are created and listed lazily. Their payload keeps the contact ID and service performer member IDs, never prices or approval tokens. Resume reloads the current catalog prices, restores the performer name and contact details/store-credit balance, confirms replacing a non-empty cart, then deletes the held record by version. Holding and completing a sale clear the active customer.
- Price override is exposed only when `POS_PRICE_OVERRIDE` is held. The lazy screen requotes the draft, compares it with list price, and grants the existing `PRICE_OVERRIDE` approval for below-list changes. The sale body sends override amounts and the approval token only when applicable; changed cart inputs invalidate the token.
- The lazy till-return sheet searches completed location orders, prioritizes the current session, selects return quantities, and submits cash returns with an attempt idempotency key.
- Credit-sale refusal is covered with the setting disabled. BN/EN labels were added. Existing route-budget and touch-target browser assertions remain in the browser suite.
