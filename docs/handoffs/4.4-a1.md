# 4.4 A1 — Website template contracts

## Result

Implemented the A1 contracts and validation layer on `s/4.4-a1-template-contracts`. A1 creates the public website-template vocabulary, platform permission/audit/rule keys, branded identifiers, strict request/content schemas, and bn/en error messages. It adds no Mongo, HTTP, event, or tenant-site behavior.

## Files

- Added `WebsiteTemplate*` contracts, status, key patterns, preset bounds, and website subpath exports.
- Added `WebsiteTemplateId` and `WebsiteTemplateRevisionId` after `DomainOperationId`, before `InvalidIdError`, and exported each from `@banijjik/ids`.
- Added platform website read/write/publish permissions. SUPPORT and BILLING receive none; SUPER_ADMIN receives them through the existing all-permissions mapping.
- Added website-template audit actions and target types, business rule keys, and the three platform error message keys.
- Added strict website-template schemas. They reuse 4.1 design and policy validators, validate registered module/kind/section-variant vocabulary, require the default preset to belong to the preset list, enforce lower kebab-case keys and preset bounds, and reject any non-empty section `imageFileId`.
- Re-exported the existing `siteTokensSchema` from `@banijjik/validation/website`; did not edit `site-design.schema.ts` (C1).
- Added bn/en translations for the three new error keys.
- Added bn/en platform-screen labels for the four website-template audit actions and two target types.

## Deviations

- D1–D7 followed. No template events, `platform.website.policy`, or ADR edits were added. `WebsiteTemplateContent` includes `defaultPresetKey` (D6). This part contains 11 production files after C1. A1D/A1A/A1S remain for their subsequent parts.
- C1–C12 followed. C2 places branded IDs at the frozen location; schema and domain enforcement will both be retained; A1S copy is reserved for A1S; C8's ADR-P4-F entry is already on main and was not changed here.
- CI exposed a platform-app catalog-coverage requirement for the new audit actions and targets. Added the six corresponding bn/en labels to the platform-screen catalogs; this brings A1 to 13 production files, still within the 15-file cap. This is the only deviation from the frozen A1 file inventory.
- No out-of-scope files were changed.
