2. **Sales Domain, Use Cases & Endpoints (`apps/api/src/modules/commerce/sales`):**
   - **Domain Layer:**
     - Created `delivery-loss.entity.ts` (`DeliveryLossClosure`, `DeliveryLossRecovery`).
     - Added `order.reconcileDeliveryLoss` transition on `Order` entity (valid from `DELIVERY_FAILED`).
     - Added domain error builders `deliveryLossAlreadyClosed` and `deliveryLossMismatch`.
   - **Infrastructure Layer:**
     - Created `delivery-loss.schema.ts` (`delivery_loss_closures`, `delivery_loss_recoveries` collections).
     - Created `mongo-delivery-loss.repository.ts` implementing `DeliveryLossRepository`.
     - Registered schemas in `register-sales-models.ts`.
   - **Application Layer:**
     - `ReconcileDeliveryLossUseCase`:
       - Enforces location permissions and `DELIVERY_FAILED` status.
       - Validates line quantities sum to order lines with $> 0$ lost units (directs to RTS when 0 units lost).
       - Consumes approval PIN via `ApprovalVerifier.consume` with `APPROVAL_ACTION.DELIVERY_LOSS_CLOSE`.
       - Restocks received/damaged units via `StockLedger.returnStock`.
       - Cancels payment summary via `payments.settleCancellation`.
       - Transitions order to `DELIVERY_LOSS_CLOSED`.
       - Publishes `sales.order.lossClosed` and records audit entry.
     - `RecoverDeliveryLossUseCase`:
       - Enforces location permissions and retrieves closure.
       - Validates recovery lines do not exceed outstanding lost quantities.
       - Consumes approval PIN with `APPROVAL_ACTION.DELIVERY_LOSS_RECOVER`.
       - Restocks physically recovered goods.
       - Updates closure line recovered counts.
       - Publishes `sales.deliveryLoss.recovered` and records audit entry.
     - `GetDeliveryLossUseCase`:
       - Fetches closure and recoveries for an order.
   - **Presentation Layer:**
     - `sales-fulfillment-tenant.router.ts`:
       - Mounted `POST /orders/:orderId/delivery-loss/reconcile`.
       - Mounted `POST /orders/:orderId/delivery-loss/recover`.
       - Mounted `GET /orders/:orderId/delivery-loss`.
