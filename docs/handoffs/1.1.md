Checked in the code:
- **Login:** a dummy argon2 verify runs for unknown identifiers. The account status is revealed only after a correct password.
- **Refresh:** the atomic `markRotated` and the successor insert run in one transaction. The rotation check comes before the expiry check, so an expired copied token still revokes its family. Reuse inside the 10 s grace is answered as a race; later reuse revokes the family.
- **Cookies:** httpOnly, SameSite=Lax, paths `/api` and `/api/v1/auth`.
- **Rate limits:** keys are hashed. Both per-IP and per-identifier login limits apply.
- **Logs:** a grep test shows no secrets in the captured logs.
