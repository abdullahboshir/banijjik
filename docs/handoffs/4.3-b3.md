## Scope Completed

1. **Typed Storefront Request Client (`apps/storefront/src/account/requests-api.ts`)**:
   - Client functions `getCheckoutDetail`, `claimCheckout`, `getRequestHistory`, and `getRequestDetail` routed via proxy (`/api/v1/storefront/orgs/:organizationId/...`).
   - Server-side fallback helper `fetchStorefrontServer`.
   - Complete TypeScript interfaces for `CheckoutDetailResponse`, `RequestHistoryItem`, `ClaimCheckoutResponse`, `RequestDetailResponse`, `CheckoutOwnerType`, and `RequestType`.

2. **Private Checkout Receipt View (`apps/storefront/src/account/checkout-receipt-view.tsx` & `checkout-receipt-cards.tsx`)**:
   - `/checkouts/[checkoutId]` private tracking screen (`robots: { index: false, follow: false }`).
   - Live status display, financial summary with `MoneyText`, contact snapshot, and individual linked request cards.
   - Hold countdown component (`HoldCountdown`) with live timer updates and expired indicators.
   - Interactive guest-to-customer claim card (`GuestClaimCard`):
     - Displays OTP phone matching status.
     - Immediate claim action for authenticated matching customers.
     - Sign-in redirect action for guest sessions.
     - Customer owner badge when already claimed/linked.

3. **Customer & Guest Request History (`apps/storefront/src/account/request-history.tsx` & `request-detail-view.tsx`)**:
   - `/account/requests` tracking view with category tabs (All, Orders, Bookings, Enrollments).
   - Empty state with browse offerings link.
   - Lost-cookie recovery help guidance card (`LostCookieHelpNotice`):
     - Advises guest users who cleared cookies or switched browsers to sign in with their verified mobile number or contact support.
   - `/account/requests/[requestType]/[requestId]` individual request detail view displaying status badges, payable amounts, item lists, and schedule/hold information.

4. **Routes (`apps/storefront/app`)**:
   - `app/checkouts/[checkoutId]/page.tsx`
   - `app/account/requests/page.tsx`
   - `app/account/requests/[requestType]/[requestId]/page.tsx`
   - All private pages marked with `robots: { index: false, follow: false }`.

5. **Bilingual Localization (`packages/i18n`)**:
   - English and Bengali translation keys added under `storefront.requests.*` and `storefront.claim.*` in `storefront/en.json` and `storefront/bn.json`.
   - Full parity maintained and verified with `npm test -w @banijjik/i18n`.
